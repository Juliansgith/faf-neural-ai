FAF Agent Network

This is the network that makes the agent's decisions, running live in this page with its real weights. Every 2 seconds of game time it reads the list of units it can see and its economy, and gives a probability to every option of five decisions. Inside the network

Left to right, this is one pass through the network for the moment above. Each strip is a layer; each cell is one number. The darker the cell, the more active that neuron is. Hover a cell to read it.

1 · Every unit, one by one

The same small network reads each unit: 26 facts about it (position, health, build progress, idle or busy, cost, weapons, speed, type) plus 16 learned numbers for its blueprint. Out come 64 numbers per unit. Shown: the units in the order the game listed them.

2 · Summary by group

4 groups × (average, strongest) × 64 = 512

The per-unit numbers are pooled separately for own units, enemies in sight, remembered enemy buildings and radar contacts: an average, and the strongest value of each of the 64. That is how any number of units becomes a fixed-size summary.

3 · Game numbers

88 inputs → 128

Economy, counts, distances, game time and what it chose last time go through their own layer of 128 neurons. Top strip: the 88 inputs. Bottom: the 128 neurons.

4 · Thinking layers

512 + 128 → 256 → 256 → 34 outputs

Both summaries are combined in two layers of 256 neurons. Five small output layers turn the last one into the 34 scores behind the bars above: 11 build options, 9 produce, 8 army, 3 commander, 3 tech.

Which units change the decision most

For every unit, the network is run again as if it could not see that unit, and the change in all five decisions is measured (0 = no change, 5 = every decision flips completely). The top units are ringed on the map.

    Is it really a neural network?

    Yes, a small one. Every layer on this page is a set of weighted sums followed by a simple rule that keeps positive values and zeroes negative ones. The weights were learned from examples, not written by hand. It is small on purpose: it will have to run inside Forged Alliance's own Lua scripting later.

    What it does not do

    It chooses the five decisions above; scripts carry them out (where to place a building, how units move and fight). It sees only what its army sees. It does not plan ahead explicitly; everything it knows is in its weights.
